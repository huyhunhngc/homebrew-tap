# huyhunhngc/tap

Homebrew tap for [SimCam Lite](https://github.com/huyhunhngc/SimCamLite), a camera for the iOS Simulator.

```bash
brew install --cask huyhunhngc/tap/simcam-lite
```

`Casks/simcam-lite.rb` is generated from `homebrew/simcam-lite.rb` in the SimCamLite repository on each release.
Please send changes there.
